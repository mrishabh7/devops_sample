How to Use

  1. Tap "Choose Files" to pick individual files, or "Choose Folder" to open an entire project folder at once — all assets load automatically.
  2. Select a file tab at the top to switch between files.
  3. Toggle source/preview with the code icon button to view the raw source of the active file.
  4. Tap "+" to add more files to the current session.
  5. Tap the trash icon to clear all files and start over.
Tip: For best results, select ALL related files (HTML + its CSS/JS/images) at once so linked resources load correctly.
